# RealEstate-EmlakApp

A full-stack real estate web application built with **.NET Core**, featuring separate API and UI projects, role-based management, real-time communication, and a live deployment.

🌐 **Live Demo:** [sbrealestate.runasp.net](http://sbrealestate.runasp.net/)

## 🚀 Overview

RealEstate-EmlakApp is a real estate management platform designed for both **administrators and real estate agents**.

### Admin

* Manage application data and listings
* Access the administrative management panel
* Manage system-wide operations

### Real Estate Agents

* Create and manage property listings
* Access a dedicated management interface
* Manage their real estate portfolio

## 🏗️ Architecture

The solution is separated into dedicated API and UI projects:

```text
RealEstate-EmlakApp
├── RealEstate.API
├── RealEstate.UI
└── RealEstateSite.sln
```

The application uses a **RESTful API and microservices-oriented architecture** to separate backend services from the user interface.

## ⚡ Key Features

* Role-based access and management
* Real estate listing management
* RESTful API
* Real-time communication with SignalR
* Data access with Dapper
* Separate API and UI layers
* Admin and realtor management panels
* Live deployment
